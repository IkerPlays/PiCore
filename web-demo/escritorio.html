Raspberry Pi OS (simulado)--:--
Terminal

En una Pi real aquí tendrías una terminal de verdad.

pi@picore:~ $ pcpi-mode home
Modo: home
Navegador

Chromium, con todo internet. En el simulador no se abre ninguna web.

En modo Iker tienes un navegador más sencillo con marcadores.

Archivos

Tu carpeta personal, USB y la música de Musix (/var/lib/pcpi/music).

Aquí no hay archivos reales.

Este es el modo Escritorio: el Raspberry Pi OS de siempre, sin nada de PiCore encima. En el simulador es solo una maqueta.
